# GreenSaaS · Frontend

Aplicación Angular. [Guía de uso](docs/GUIA_USO.md), [documentación técnica](docs/README.md) y [arranque completo](../backend/docs/OPERACION.md).

Desde frontend, instalar con `npm ci` y arrancar con `npm start`. El backend se inicia en otra terminal con sus variables de entorno. La interfaz local utiliza el puerto 4200 y la API el 8080.

Verificación documental desde la raíz: `node docs/verificar-documentacion.mjs`. Para pruebas y compilación, consultar [Pruebas](../backend/docs/PRUEBAS.md).
