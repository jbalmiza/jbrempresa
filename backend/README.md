# GreenSaaS · Backend

API Java/Spring Boot. [Arranque y operación](docs/OPERACION.md), [contrato API](docs/API.md), [modelo de datos](docs/MODELO_DATOS.md) e [índice completo](docs/README.md).

Desde backend, ejecutar `.\mvnw.cmd spring-boot:run` en la terminal con las variables requeridas. La guía de operación explica Java, PostgreSQL, secretos y verificaciones.

Verificación documental desde la raíz: `node docs/verificar-documentacion.mjs`. Consulte [pruebas](docs/PRUEBAS.md) y [limitaciones actuales](docs/LIMITACIONES.md).
